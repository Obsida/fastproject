## 📌 О проекте

Этот Telegram-бот предоставляет три основные функции:

1. **🌤 Погода** — получение актуальной погоды в любом городе мира через Open-Meteo API
2. **⚠️ Анализ токсичности** — проверка текста на наличие оскорблений, угроз и опасного контента с помощью модели `cointegrated/rubert-tiny-toxicity`
3. **💱 Курсы валют** — отображение актуальных курсов основных валют относительно USD

Бот написан на Python с использованием библиотеки `pyTelegramBotAPI` и поддерживает интуитивное меню с навигацией.

## 🚀 Установка

### 1. Клонируйте репозиторий

```bash
git clone <your-repo-url>
cd <project-folder>
```

### 2. Создайте виртуальное окружение (рекомендуется)

```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Linux/Mac:
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

> 📝 Если файла `requirements.txt` нет, создайте его с содержимым из раздела [Зависимости](#-зависимости)

### 4. Настройте бота

1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
2. Получите токен и вставьте его в код:

```python
bot = telebot.TeleBot("ВАШ_ТОКЕН_ЗДЕСЬ")
```

### Переменные окружения (опционально)

Для безопасного хранения токена рекомендуется использовать `.env` файл:

```env

```

И подключите через `python-dotenv`:

```bash
pip install python-dotenv
```

### Загрузка модели токсичности

При первом запуске бот автоматически загрузит модель `cointegrated/rubert-tiny-toxicity` (~400 МБ). Убедитесь, что:

- Есть доступ к интернету
- Достаточно места на диске
- Установлены `transformers`, `torch`, `sentencepiece`

> 💡 Для ускорения загрузки на GPU убедитесь, что установлен `torch` с поддержкой CUDA

## 🛠 Разработка и запуск

### Локальный запуск

```bash
python main.py
```

### Запуск в фоне (Linux)

```bash
nohup python main.py > bot.log 2>&1 &
```

### Использование systemd (production)

Создайте файл `/etc/systemd/system/telegram-bot.service`:

```ini
[Unit]
Description=Telegram Weather/Toxicity/Currency Bot
After=network.target

[Service]
User=your_user
WorkingDirectory=/path/to/project
ExecStart=/path/to/venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Активация:

```bash
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
```

## ⚠️ Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| ❌ Модель не загружается | Проверьте интернет, место на диске, установите `torch` с нужной версией |
| ❌ Таймауты при запросах | Увеличьте `REQUEST_TIMEOUT`, проверьте прокси/фаервол |
| ❌ Город не распознаётся | Попробуйте написать название на английском или уточните запрос |
| ❌ Ошибка 429 (Rate Limit) | Добавьте задержки между запросами или используйте прокси |
| ❌ Бот не отвечает в Telegram | Проверьте токен, интернет-соединение, логи консоли |
